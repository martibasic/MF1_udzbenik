# Liberation Sans 2.1.5

Unmodified Regular, Bold, Italic and BoldItalic TTF files from the
[upstream 2.1.5 release](https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5),
[TTF archive](https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz).
Redistributed under the included SIL Open Font License 1.1.

The PDF renderer disables system font discovery and explicitly includes this
directory. SVG labels therefore use the same Liberation Sans fallback on
Windows and Linux. Body text and mathematics use Typst's embedded fonts;
Quarto supplies Font Awesome. No system-wide font installation is required.
